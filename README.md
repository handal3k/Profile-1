# Profile-1 assets

Public image assets used by the `Jack · 1888` SillyTavern character card.

Base URL after GitHub Pages is enabled:

```text
https://handal3k.github.io/Profile-1/assets/jack-1888/
```

## Layout

- `avatar/`: Jack dialogue portrait
- `banners/`: rotating status-bar banners
- `locations/`: location-aware status-bar scenes
- `manifest.json`: stable asset lookup table

The current location set covers Whitechapel Police Station, Buck's Row,
Hanbury Street, Dutfield's Yard, Mitre Square, Goulston Street, and
Miller's Court / Dorset Street, with a generic Whitechapel fallback.

Use versioned filenames when replacing a published image so browser caches do not keep an older copy.
